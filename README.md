# Git Basic Task

## Used commands:
1. `mkdir git_basic_task` and `cd git_basic_task` - create a directory and navigate into it
2. `git init` - initialize a local repository
3. `git branch -M main` - rename the default branch to main
4. `git add <file>` - add a file to the staging area
5. `git commit -m "message"` - create a commit
6. `git remote add origin <url>` - connect the remote repository
7. `git pull origin main --allow-unrelated-histories --no-rebase` - merge independent histories
8. `git push -u origin main` - push local changes to GitHub
